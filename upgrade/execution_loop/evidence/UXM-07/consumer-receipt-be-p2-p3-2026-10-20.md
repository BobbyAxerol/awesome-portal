## 1. What changed in the testkit (task 1)

`v2/testkit/schema.ts` implements `dependentRequired` exactly per JSON Schema 2020-12 §10.2.2.4 (a trigger that is an own member of the object requires every listed member to be an own member; a present `null` counts as present; an absent trigger imposes nothing; an inherited name never triggers; a non-array list throws) and `minProperties` (the paper-read schema uses it). Unit tests pin both, plus the identity rule on the real `DeploymentIdentityRules`. Any other unknown keyword still throws; the guard test now plants `unevaluatedProperties`. **Added keywords: `dependentRequired`, `minProperties`.** Nothing else was needed by the new schemas.

### Where the real server shape differed from what the screens assumed (BE-P3 "FE vs server")

All seven probes of `e2e/bffDoubleAlpha.ts` now pass the schemas (`fixtureBff/server.test.ts`, 137 tests; each double body is built from the canonical case and overlaid, never hand-shaped):

1. Alpha resource: `delivery_profile`, `requested_environment`, `resource{kind,id,label}`, `projection[]`, `actor`, populated `panels`, `valuation_warning`, `strategy_id` per deployment; health is READY | ATTENTION | FINDING.
2. **Screen fix:** `alpha_label` is the literal "Unnamed alpha", `version` "UNVERSIONED", a deployment's `portfolio_name` is null. The title is now the alpha id; name and version are `Not published (FE-066)` (the literals are never printed); the portfolio name is joined from `data.alpha.portfolios[]` on `portfolio_id`.
3. Subject records: no `projection.completeness` (they carry `received_at_ms`), the cursor is a Portal-signed `kc1.` token (the double minted `orders-p2`).
4. **Reader fix:** the observed timeline is a full panel envelope; its freshness lives in `clocks`, not `freshness` (`api/observedTimeline.ts` now reads `clocks.as_of_ms` / `read_at_ms`, falling back to the old name for the unit fixtures).
5. Venue candles: no `environment` / `profile_id`, `source.note` always a string, `trades` per candle.
6. Equity chart: `portal.execution.financial-chart.v1`; **gaps are never published** (`coverage.gaps` empty, `preserves_gaps` false), the series id is `account:<id>:currency:<ccy>`. The double drops its declared gap; the reader's gap handling stays covered by a test that builds a reader-level gap and says so.
7. The symbol absence uses the canonical `feature_disabled` case.

## 5. Honesty checks that the suites hold
