GET /api/v1/quantbt/runs/rrun_ef3e10730fcb16a884ee6dfed3bd87f3/report   (own run R-WFO-019, CANCELLED)

While the library read is outstanding the notice is `loading`, not `denied`. "Read again" is offered only when the library row's status is DRAFT / QUEUED / RUNNING / SEALING.

**Title / crumb.** The same library read teaches the label registry the `R-…` label, so the chip and the shell crumb print `R-WFO-019` instead of `rrun_ef3e1073` (the report read never could: it 404s).
