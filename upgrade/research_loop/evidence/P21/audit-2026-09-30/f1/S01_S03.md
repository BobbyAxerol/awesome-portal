## FG 03-T — transport label lied while loading / after 503 / 409 / 400 — DONE

- **Was:** `TransportDot`: `!live → SSE_CLOSED` = "stream closed at terminal frame" for every state with no live status — a page that had
  read nothing yet, and a read the server refused.
- **Now:** pure `transportFace()` (exported) chooses the words; order = never-had-a-source > final > no read yet / refused > a read exists:
  - COMPLETED / FAILED / CANCELLED or the source's terminal frame → `stream closed at terminal frame` (also when a later console read was refused);
  - cancelled before the source reported → `no stream · cancelled before the source reported` (it never had a terminal frame);
  - no read yet, nothing refused → `no stream yet · waiting for the first read`;
  - refused first read → `no stream · server unavailable (503)` / `stream closed · the run's state moved (409)` / `no stream · request refused (400)` /
    `no stream · access refused (403)` / `no stream · the server did not answer` (status 0) — the status the server gave, nothing guessed;
  - a live run keeps the transport's own label (stream / dropped-polling / resting); a retryable refusal on a live read does **not** relabel it
    (the poll floor is still running), only a refusal that stops the floor (409, 400) does.
  The dot carries `data-transport-state` for tests.
- **Tests** (`runProgress.f1.test.tsx`): one per state — loading; 503/409/400/403 (`it.each`); transport error; the screen after a 503 first read;
  final run incl. refused console; source terminal; cancelled-before-source; the three live transports; retryable-vs-stopping refusal.
- **Browser** (`page.route` fails the real progress read with the status; loading = first read held 2.5 s): `no stream yet · waiting for the first read`
  (`s03_loading.png` `b9ceab9bc329e1fb`), `no stream · server unavailable (503)` (`s03_refused_503.png` `eb90db54422b21a4`),
