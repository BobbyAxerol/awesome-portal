## Decisions made

- Window-bars reason code is in tooltip + aria-label, not printed (three windows would repeat a 47-character code in a 290 px rail); same pattern as the other not-published chips.
- A 400 with a problem code is shown as that code (served, not invented); a 400 without a code, 5xx and a body that is not metadata leave no count, silently.
- `symbolListing.partial` also reads `truncated: true`; `total: null` never means "unlisted" (only an exact `total: 0` does).
- Quality chip in a list row appears only when a gap, duplicate or missing ratio exists (the row's bars line already prints `0 gaps`).
