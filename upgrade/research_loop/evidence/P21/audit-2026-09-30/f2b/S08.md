## Decisions (and why)
1. **One overview.** `candle_overview` is the only chart source. `market_overview` is drawn only when `candle_overview` is absent AND `market_overview.state === AVAILABLE` (rolling deploy), with a "source overview" chip; never both. Verified on real P04 R-P04-018: both AVAILABLE, 744 bars, 47 buckets of 16, identical envelope (66924.1 / 57758.6) and `values` byte-equal. Fallback applies to the hub lane only (the retained `Replay` has no `market_overview`).
2. **Three windows.** Overview strip shows IS (active fold's train span, hatched), every fold's OOS (solid, active stronger, click = open that fold), HOLDOUT as a typed-absence legend chip (never a band). IS position comes from served bucket `open/close_utc_ms` (linear inside a bucket, positioning only). Tooltip per band = served start/end; OOS bars = `segment.bars`; IS bars = "not published" (the fold plan has none; not computed).
3. **Window switch `IS | OOS | HOLDOUT`** lives in the fold-chain row, same chip style. `?window=` (query, default `oos` omitted) + fold stays in the hash. Written with replaceState (no history spam, hash preserved), re-read on popstate. OOS = today's replay chart; IS = bucketed candles of the train span (no markers, labelled "overview"); HOLDOUT = served typed absence + code + link to Split.
4. **IS with no coverable overview** says "IS overview — not published" with the served split reason code if any; no FE-invented code.
5. **Markers**: custom SVG overlay on lightweight-charts (library kept; built-in marker plugin no longer used). Glyph 12–18px by bar spacing, 2px `--paper-raised` halo, tokens only. Long entry green ▲ below low; short entry red ▼ above high; exit ■ softened in the closed side's colour (long exit above, short exit below); flip two-tone ◆; resize small ◆. Letter tag L/S/X/F/R, close price on hover/selected. Dotted connector opener→closer by served order (RESIZE skipped; ambiguous = none). Hover card (kind, side, time, close, notional, fee; absent = "not published"). Ring pulse 0.18s, off under reduced-motion / `smokeMotionAllowed()` false. Click moves playhead + selects ledger row; ledger hover ⇄ marker hover.
6. **Orders / fills / SL-TP / OCO are not drawn** (not served). Capability strip: chips orders · fills · partial · trades · SL/TP · OCO · multi-leg, state dot + tooltip with server sentence and code; code also as sr-only `data-reason-code`. Replaces the "route-aware facts" card.
7. Fixed a pre-existing race exposed on screen: after a window arrived, `getVisibleLogicalRange()` right after `fitContent()` was stale, so the playhead "slide" shrank the view to ~100 of 168 bars. A just-fitted window no longer slides.
