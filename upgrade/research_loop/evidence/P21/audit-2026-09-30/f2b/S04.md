## Decisions
- `?window=` lives in the query string, not the hash codec (`inspectionCursor.ts` is shared and the S08 brief reads `?window`). S08's own link also needs `fold`; the hub carries it in the hash, as every deep dive link already did.
- Hub publishes OOS only: IS/Holdout selection shows "not published" (no reason code; `reason_code: null` is the existing hub pattern), never relabelled OOS numbers. FE does not invent a code.
- Heading = link; the duplicate button was removed (same target, fewer words). `data-deep-dive` kept on the heading anchor.
- "next" on Claim -> report; Atlas is an aside, so only "prev".
- Embedded S05-S08 bodies read `?window` themselves from the shared URL (other groups' files).
