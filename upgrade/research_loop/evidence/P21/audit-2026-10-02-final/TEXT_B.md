## 3.7 The collapsed pattern for repeated absence (lists and tables)

Rule: an absence repeated N times in a column/list is a property of the table, not of the rows.
1. Row/column level: if every loaded row of a column is the same typed absence (or the same constant), hide the column and print ONE caption under the table header: `seed — not published · state — all complete · OOS — not scored at search (Stage B)`. The reason code is the caption's `title`; the typed word comes from the server reason (rule a), not a FE-invented phrase. Partial columns (some rows value, some absence) keep the column and render the absence as a muted `·` with the sentence in `title` plus an `aria-label` equal to the sentence; a footer line `7 of 100 not published` states the count. Never a `0`, `-` or `N/A` as value.
2. Same pattern for S01 `rc — not published` x43, S04 `pending source` x15, S08 route facts (6 groups x label + `not published` + code), S09 source absences: one line `Not published by this source (6): orders · fills · trades · positions · events · funding` with per-name tooltip = reason sentence + code. 3.
