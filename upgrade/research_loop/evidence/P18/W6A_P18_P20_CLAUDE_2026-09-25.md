## 1. What changed, in one paragraph

A report is now sealed on **both** lanes. A P04 fixed-profile run keeps its
P13–P17 hubs; a Delta WFO run — which never had those hubs and so never got a
report — is sealed from the retained current-source reads Screens 04–08
already serve (claim strip, fold verdicts, fold plan, selection, freeze,
replay, equity). Both produce `research.report-frozen-core.v2`, an additive,
versioned shape: a stored v1 core stays byte-identical and readable
(`FrozenCore = oneOf[V1, V2]`). Compare reads the same retained facts for WFO
runs (claim, OOS Sharpe / decay, per-fold OOS Sharpe, extrema-bucket small
multiples, the retained outer-test span for a pair) and gains the additive
fields S13 asked for. Screens 09 and 13 consume every new field, in the hi-fi
positions, with DQ-08 number formatting and the exact server string kept one
hover away.

## 3. Decisions (W6A-Dnn)

| # | Decision | Why |
|---|---|---|
| D01 | Frozen core **v2** as a versioned union; every new seal is v2 on both lanes; a v1 row is never rewritten. A duplicate terminal callback of an old P04 run seals a new v2 revision; the read serves the newest. | Sealed facts are immutable; additive without a migration. |
| D02 | The WFO report sidecar is best-effort at `run_completed`: a failure is logged (`research_report_rs02_materialize_failed`) and never refuses the run's own terminal lifecycle; a duplicate terminal retries it. | The P04 sidecar's "retry forever" would hold a WFO run hostage to a report. |
| D03 | Certification is a typed NOT_PUBLISHED field on S09 and S13; the hi-fi box keeps its place with the reason. | No grade policy or cap source exists; a grade would be invented. |
| D04 | WFO passport = the engine's claim strip (hi-fi keys); P04 passport = its six hub facts, now named. | Hi-fi passport is "issued by the engine, quoted verbatim". |
| D05 | Stage checks: S1 fold plan retained (CAVEAT without holdout), S2 `oos_used_for_selection` (CAVEAT if true), S3 retained import digest MATCH/MISMATCH, S4 retained model positions, S5 fold verdict counts under `research.fold-verdict.v1`. P04: S3 from P16 integrity (PARTIAL → CAVEAT), others NOT_PUBLISHED. | Each check is one sourced fact with its key; never a PASS from progress. |
| D06 | IS equity = retained final-account path before the first outer test; OOS = observations inside test windows; both extrema-preserving to ≤300/≤600 points. | The retained path is one retrospective account; labelled by scope. |
| D07 | Artifacts are the sealed part digests; bytes are never downloadable from the report (P05: a GET never reopens private bytes). | Honest filenames without a fake link. |
| D08 | Report GET never 409 (declared in OpenAPI); S09 read lane drops the 409 branch. | Code and contract already agreed on 404. |
| D09 | S09/S13 display numbers via `researchFormat` (DQ-08); the exact server string stays in `title` / `data-exact` / `data-*-value`. The earlier "print raw strings" rule is superseded on these screens. | Hi-fi prints "+28.4%", "1.19"; the task asks for researchFormat. |
